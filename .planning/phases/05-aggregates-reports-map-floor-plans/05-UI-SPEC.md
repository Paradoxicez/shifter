## Spacing Scale

Declared values (multiples of 4). Inherited from all prior phases — no new exceptions.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline badge padding, sparkline tick gaps |
| sm | 8px | Compact control spacing, table cell padding, sidebar item gap |
| md | 16px | Default element spacing, card content padding, form field gap |
| lg | 24px | Section padding (`p-6`), card header, floor-plan sidebar section gap |
| xl | 32px | Layout gaps between page sections, report-result panel spacing |
| 2xl | 48px | Major section breaks between summary and detail in report view |
| 3xl | 64px | Page-level top padding on full-bleed map view only |

Exceptions:
- **Map container:** `h-[calc(100vh-3.5rem)]` full-bleed minus topbar height (56px). No page padding on map route.
- **Floor-plan canvas:** occupies remaining width after 256px sidebar; no internal padding — pins float freely over the image.
- **Leaflet popup:** internal padding follows Leaflet defaults (12px/16px); override with `leaflet-popup-content` targeting in a CSS layer.
- **Download tile grid:** three tiles in a row with 16px gap (`gap-4`); each tile min 160px.

Source: Established in Phase 1 UI-SPEC, carried through Phases 2–4. All Tailwind spacing values remain on the default 4px scale.

| Muted | `--muted-foreground` | `oklch(0.45 0.020 240)` | Secondary text, report period labels, "vs prior period" footer, map popup secondary text |
| Destructive | `--destructive` | `oklch(0.55 0.22 27)` | Remove pin confirmation, delete floor plan, decommissioned-device badge |
| Success | `--success` | `oklch(0.62 0.18 145)` | Floor-plan device marker — healthy state (green dot), CAGG freshness badge |
| Warning | `--warning` | `oklch(0.75 0.16 70)` | Floor-plan device marker — warning state (yellow dot), battery-low indicator |

Accent (`--primary`) is reserved for:
1. Primary action buttons: "Generate report", "Upload floor plan", "Save pin", active sidebar nav link
2. Site map marker fill (building glyph, navy)
3. Leaflet cluster icon fill (navy circle)
4. "View site" button inside map popup
5. Report download tile hover/focus ring
6. Period-range preset button selected state (mirrors DateRangePicker from Phase 4)

Device-state dot colors (floor plan, D-22):
- Green dot: `bg-success` (`--success`) — healthy
- Yellow dot: `bg-warning` (`--warning`) — warning (battery ≤ 20% or RSSI < −110 dBm or recent decode_fail)
- Red dot: `bg-destructive` (`--destructive`) — offline (last_seen > 2× expected_interval)
- All dots: 12px diameter (`h-3 w-3`), `rounded-full`, 2px white ring (`ring-2 ring-white`)

Gateway marker:
- Slate fill: `text-muted-foreground` fill — antenna glyph
- Online/offline ring: `ring-success` or `ring-destructive` 2px ring on the divIcon

## Interaction States

### Report Generation Flow (D-06)

```
[Config panel]
  → user fills scope + range + grouping
  → clicks "Generate report"
  → API call POST /api/reports/generate
  → on success: config panel replaced by [Result panel]
    ├── CSV tile: "Download CSV" button (immediate href download)
    ├── Excel tile: "Download Excel" button (immediate href download)
    └── PDF tile: "Generating PDF…" + Loader2 spinner
          → SSE or poll GET /api/reports/:id/status
          → when status=ready: tile becomes "Download PDF" button
          → sonner toast fires: "Your PDF is ready — click to download."
  → navigate away: result panel lost (no persistence)
```

Loading states:
- Generate button: shows `Loader2` spinner + "Generating…" text; disabled during request
- CSV/Excel tiles: disabled until generate completes
- PDF tile: `Loader2` spinner while job pending; `Download` icon when ready

Error state: replace result panel with `Alert` variant destructive + retry link back to config.

### Floor Plan Pinning Flow (D-20)

```
[FloorPlanTab loaded]
  → DeviceSidebar shows "Unplaced devices (N)"
  → user clicks device row
    → row highlights (bg-primary/10 + border-primary)
    → cursor on canvas: crosshair + ghost marker follows pointer
  → user clicks on canvas
    → pin lands at (x_frac, y_frac) coordinates
    → PATCH /api/floor-plans/:id/placements
    → device moves from "Unplaced" list to "Placed" list in sidebar
    → no toast (silent confirmation — pin visible immediately)
  → user right-clicks existing pin
    → context action "Remove from plan"
    → RemovePinAlertDialog opens
    → on confirm: pin removed, device returns to unplaced list
  → user drags existing pin
    → pointer-events based drag
    → PATCH on dragend
    → no toast (silent)
```

### Map Drill-Down Flow (SITE-06)

```
/map
  → Leaflet tiles load; markers cluster if >50
  → user clicks site marker
    → Leaflet popup opens (SitePopup)
  → user clicks "View site"
    → navigate to /sites/:id
    → site detail defaults to Floor plan tab if floor_plan rows exist (D-23)
    → otherwise Overview tab with "Upload floor plan" empty-state CTA
```

### PDF → PNG Conversion Flow (D-17)

```
UploadFloorPlanDialog
  → user drops/selects PDF file
  → client detects mime type = "application/pdf"
  → show "Converting PDF to image…" progress bar
  → pdf.js renders first page to <canvas> at 150 DPI
  → canvas.toBlob('image/png') → PNG blob
  → swap file input value with PNG blob
  → show PNG thumbnail preview
  → enable "Upload" button
  → server receives PNG only
```

## Floor Plan — Canvas Coordinate Contract

Positions stored as normalized fractions `x_frac, y_frac ∈ [0.0, 1.0]`.

Rendering formula (executor must use exactly):
```
pin_left_px = x_frac × container_width
pin_top_px  = y_frac × container_height
```

Container (`FloorPlanCanvas`): `position: relative; width: 100%; height: auto` — image natural aspect ratio preserved via `<img style="width:100%;display:block">`. Container dimensions read via `getBoundingClientRect()` at click/drag time.

Drag: pointer events on the `DevicePin` div; update `x_frac/y_frac` on `pointerup`. Debounce PATCH call 300ms.

Touch: `touch-action: none` on canvas to prevent scroll conflict during pin placement.

### Period-Delta Display (D-03)

- Always show: `Δ vs prior period` — `+12.3%` (green/red) or `−8.1%`
- Conditionally show: `vs same period last year` — shown only when ≥1 measurement exists in prior-year window
- Silent fallback: if no prior-year data, the YoY column/tile is absent entirely (no "N/A", no dashes)
- Color convention: water positive delta → `text-warning` (potential leak); electricity delta → `text-muted-foreground` (mirrors KpiCard color contract from Phase 4)

### Export Formats

**CSV (REPT-03):**
- Encoding: UTF-8 with BOM (`\xEF\xBB\xBF`)
- Separator: comma
- First 3 rows: metadata header block (report title, generated timestamp in install_tz, scope description)
- Data: Detail rows only (per-period breakdown); no chart data
- Timestamps: ISO-8601 with timezone offset

**Excel (REPT-04):**
- 3 sheets: "Summary", "Period Detail", "Meter Detail"
- "Summary" sheet: period metadata + totals + delta values
- Dates formatted as Excel dates (not strings)
- Units in column headers: `Consumption (m³)` or `Consumption (kWh)` per install unit setting
- Totals row: bold + top-border
