```json
    "time": "...",

    "instant_value": 4.2,
    "quality": "ok",
    "battery_pct": 87,
    "rssi": -65,
    "snr": 8.5,

    "decoded_object": {...},

    "by_quality": {"ok": 97, "decode_fail": 2, "out_of_range": 1}
  },
  "online": true | false | null    // null if no device bound
}
```

`GET /api/metering-points/:id/uplinks?limit=100&before=2026-05-11T12:00:00Z&quality=ok,decode_fail`:
```json
{
  "uplinks": [
    {
      "time": "...",
      "cumulative_value": 1234.56,
      "instant_value": 4.2,
      "battery_pct": 87,
      "rssi": -65,
      "snr": 8.5,
      "fcnt": 428,
      "quality": "ok",
      "raw_payload_hex": "0a 1f 3c 4d",
      "decoded_object": {...}
    }
  ],
  "has_more": true,
  "next_before": "<iso of oldest row>"
}
```

- `limit` default 100, max 500 (D-16 cap)
- `before` cursor on time DESC
- `quality` comma-separated list (filter `WHERE quality = ANY($)`)
- `quality=` empty → no filter
- Index used: `measurement_mp_time_idx (metering_point_id, time DESC)` for the no-filter case; `measurement_quality_flagged_idx` for the `quality != 'ok'` filter (verified in 0015)

`GET /api/metering-points/:id/timeseries?range=today|24h|7d|30d|custom&start=...&end=...`:
Same shape as Plan 04's dashboard timeseries but single-MP scope; reuses `MeteringPointTimeseries` query from Plan 04. NOTE: Plan 04 added the query to `timeseries.sql`; this plan just consumes it via the handler.

`GET /api/metering-points/:id/signal-history` — fixed window for sparklines (D-17):
```json
{
  "window_start": "...",
  "window_end": "...",
  "bucket_interval_seconds": 3600,
  "series": [
    { "bucket": "...", "battery_pct": 87.0, "rssi": -65.0, "snr": 8.5 }
  ]
}
```
- Always last 24h, hourly buckets (D-17 fixed)
- Reuses `MeteringPointTimeseries` query with range=24h params

**raw_payload_hex format:** lowercase, space-separated bytes, e.g. `"0a 1f 3c 4d"` (D-18). Implement as Go helper: `func toHex(b []byte) string`.

**Quality summary window:** last 100 uplinks (D-19 "X of last 100 uplinks flagged"). Compute via `ORDER BY time DESC LIMIT 100` then aggregate in Go (or use a single SQL with `count() filter (...) over (window)` — Go aggregation is simpler).

**D-22 empty case:** MP exists, no binding, no measurements → 200 with `active_binding=null, latest_reading=null, quality_summary={window_size:0, flagged_count:0, by_quality:{}}, online=null`. Frontend disables Advanced + Uplinks tabs based on `latest_reading == null`.

**Online flag:** apply D-07 rule to the bound device's last_seen_at vs its profile's expected_interval_s. Use existing JOIN to device + device_profile in detail query.

| `:id` path parameter → SQL | UUID-typed; parse + reject malformed before DB hit |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-05-01 | Tampering | `:id` not a valid UUID | mitigate | `uuid.Parse(chi.URLParam(r, "id"))`; 400 on parse error. |
| T-04-05-02 | Denial of service | client sends limit=999999 | mitigate | Hard cap limit ≤ 500 per D-16; reject 400 otherwise. |
| T-04-05-03 | Tampering | quality filter contains arbitrary SQL | mitigate | Whitelist validation against `{ok, decode_fail, missing_canonical, out_of_range, duplicate_fcnt}` before sqlc. |

| T-04-05-05 | Denial of service | huge JSONB extra renders slowly | accept | JSONB blobs are sized by vendor; single-tenant install can tolerate. |

```sql
-- name: ListUplinksByMP :many
-- DETL-02: cursor-paginated, time DESC, optional quality filter.
-- Index path: measurement_mp_time_idx (metering_point_id, time DESC).
-- $1 = mp_id, $2 = limit (≤500), $3 = before (nullable timestamptz cursor),
-- $4 = quality filter (TEXT[]; NULL or empty = no filter).
SELECT
    time, cumulative_value, instant_value,
    battery_pct, rssi, snr, fcnt, quality,
    raw_payload, decoded_object
FROM measurement
WHERE metering_point_id = $1
  AND time < COALESCE($3::timestamptz, 'infinity'::timestamptz)
  AND (
      $4::text[] IS NULL
      OR cardinality($4::text[]) = 0
      OR quality = ANY($4::text[])
  )
ORDER BY time DESC
LIMIT $2;

-- name: QualitySummaryByMP :many
-- D-19: window of last 100 uplinks, grouped by quality.
-- Returns one row per quality value present in the window.
SELECT quality, COUNT(*)::bigint AS count
FROM (
    SELECT quality FROM measurement
    WHERE metering_point_id = $1
    ORDER BY time DESC
    LIMIT 100
) recent
GROUP BY quality;
```

2. Create `internal/db/queries/mp_detail.sql`:

```sql
-- name: GetMeteringPointDetail :one
-- Composite query: MP + site name + active binding + latest reading.
-- All bindings/measurements are LEFT JOINs so D-22 (no binding / no uplinks) returns the MP row.
-- $1 = mp_id
SELECT
    mp.id, mp.name, mp.site_id, mp.utility_class, mp.location_description,
    s.name AS site_name,
    -- active binding fields (LEFT JOIN)
    b.id AS binding_id,
    b.device_id,
    b.valid_from,
    d.dev_eui,
    dp.name AS device_profile_name,
    -- latest reading via LATERAL
    latest.time AS latest_time,
    latest.cumulative_value,
    latest.instant_value,
    latest.quality,
    latest.battery_pct,
    latest.rssi,
    latest.snr,
    latest.fcnt,
    latest.decoded_object,
    latest.extra,
    latest.raw_payload
FROM metering_point mp
LEFT JOIN site s ON s.id = mp.site_id
LEFT JOIN binding b ON b.metering_point_id = mp.id AND b.valid_to IS NULL
LEFT JOIN device d ON d.id = b.device_id
LEFT JOIN device_profile dp ON dp.id = d.device_profile_id
LEFT JOIN LATERAL (
    SELECT time, cumulative_value, instant_value, quality, battery_pct, rssi, snr, fcnt, decoded_object, extra, raw_payload
    FROM measurement m
    WHERE m.metering_point_id = mp.id
    ORDER BY m.time DESC LIMIT 1
) latest ON TRUE
WHERE mp.id = $1 AND mp.archived_at IS NULL;

-- name: MeteringPointOnlineStatus :one
-- D-07: online = bound device's last_seen_at within 2× expected_interval_s.
-- Returns NULL if no binding (D-22 empty case).
SELECT
    CASE
        WHEN b.device_id IS NULL THEN NULL
        WHEN d.last_seen_at > now() - (2 * dp.expected_interval_s * INTERVAL '1 second') THEN TRUE
        ELSE FALSE
    END AS online
FROM metering_point mp
LEFT JOIN binding b ON b.metering_point_id = mp.id AND b.valid_to IS NULL
LEFT JOIN device d ON d.id = b.device_id
LEFT JOIN device_profile dp ON dp.id = d.device_profile_id
WHERE mp.id = $1;
```
