## Problem

`internal/install/handlers.go:writeSecret` called `os.WriteFile(path, ...)` unconditionally.
In the bundled compose flavor, `deps.SecretsDir = "/run/secrets"` is a READ-ONLY docker
secrets mount. `os.WriteFile` returned `permission denied` → step 2 handler returned 500
`secret_write`.

Discovered during install rehearsal 260513: wizard step 2 failed after
`bootstrap-chirpstack-token.sh` had already written the token to the host file
(`secrets/chirpstack_api_token.txt`), which compose mounts at `/run/secrets/chirpstack_api_token`
as a RO bind.

## Fix

### Task — Make writeSecret idempotent under RO docker secret mounts

**Files modified:**
- `internal/install/handlers.go` — rewrote `writeSecret` with skip-if-matches logic
- `internal/install/writesecret_test.go` — new file, 3-case table-driven test

**Logic:**
1. `strings.TrimSpace` the operator-provided value (paste artifacts)
2. If file exists and `strings.TrimSpace(existing) == value` → skip write, return path
3. If file exists but content differs → return error ("different content (RO docker mount?)")
4. If file absent → `os.MkdirAll` + `os.WriteFile` as before

**Tests:** 3 cases — absent (write), match (skip, mtime unchanged), mismatch (error)

**Verification:**
- `go test ./internal/install/... -count=1` → 38 passed
- Live wizard: step1→200, step2→200 (was 500), step3→200, step4→200, finish→200, login→200
